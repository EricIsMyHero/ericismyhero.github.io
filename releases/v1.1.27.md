# UNEC Students Hub v1.1.27

24 November 2026

This release adds **Student+ benefits** and a **campus-to-campus route guide**. It also improves theme contrast, unifies account previews and makes career drafts easier to prepare.

[Azərbaycan dilində buraxılış qeydləri](https://github.com/EricIsMyHero/ericismyhero.github.io/blob/v1.1.27/releases/v1.1.27.az.md)

## ✨ What's new

### 💳 Student+ benefits

- Open **137 offers** across 17 categories from **Features**. The catalogue includes 104 TələbəPlus offers, nine other local student offers and 24 online student programmes. [Student+ benefits](https://unecstudentshub.com/#/student-plus)
- Search by brand, service or address. Filter by category and redemption method, sort by highest discount or brand name, and save favourites in the current browser.
- Preview cards show the brand artwork, category, name and discount or offer type. Icons distinguish QR, card, Visa PayCity, student ID and online redemption methods.
- **View details** opens redemption steps, eligibility, available branch addresses and hours. For local percentage offers, the calculator estimates savings and the final price. The catalogue links to the TalabaPlus app and Birbank card information.

### 🧭 Campus-to-campus route guide

- **Student Compass** now covers **12 directions** between the İçərişəhər, Gənclik, Nizami and Semaşko campuses. Pick the start and destination, or swap them with one button. [Route guide](https://unecstudentshub.com/#/compass/korpuslararasi-marsrut)
- See applicable metro stations, bus numbers, stop codes, transfers and walking options. Open Google Maps to check current directions.

### 🎨 Themes and profile previews

- Improved text, icon, selected control and form contrast across **11 themes**. Selected course, major and section buttons now have legible dark labels on white in Midnight.
- The header profile button, **Dashboard** and **More** share the same avatar styling. They show the account photo when available from a sign-in provider or the saved profile, with a name initial as the fallback.
- Removed the **See all** shortcut next to **Latest news** on Home.

### 🛠️ Admin panel and career listings

- All career listing content fields are optional. Admins can save an empty draft. Published listings show the supplied information and include an application button when a link is present.
- Increased **Company or organisation** from **100 to 500 characters** and **Description** from **2,000 to 8,000**. Title and schedule allow **300** each, location **500**, and application URL **2,048**. The site keeps the full description and shortens the Telegram message to fit its limit.
- Push notification titles and bodies, and workspace task titles, are optional. A blank notification title defaults to **UNEC Students Hub**.

## 🧪 Quality checks

- **170 JavaScript and 3 Python tests passed.** Generated-site, material-date and JavaScript syntax checks passed.
- Browser checks covered contrast, account photos, offer search and favourites, campus selection and admin drafts. Account and admin checks used isolated data.
