# UNEC Students Hub v1.1.26

20 November 2026

A new Career Board, a searchable Features directory, a simpler mobile sidebar and eight new study PDFs.

[Azərbaycan dilində buraxılış qeydləri](https://github.com/EricIsMyHero/ericismyhero.github.io/blob/v1.1.26/releases/v1.1.26.az.md)

## ✨ What's new

### 💼 Career Board and Telegram

- Added a public **Career Board** for internships, volunteering and training. Browse active listings by programme type and field, see application deadlines, and follow the organiser's application link.
- Training listings support a longer description, event dates and times, and a venue. The event schedule and application deadline have separate fields. Listings with a deadline stay active through that day in Baku time.
- Added **Career Listings** to the admin panel. Save a draft, review it and approve it for publication. The dashboard shortcut opens the form, and saving a draft brings the approval button into focus.
- Approved listings can be posted to the dedicated [UNEC Students Hub career channel](https://t.me/unecstudentshubcareer). The admin panel shows the Telegram delivery status and links to successful posts. If delivery is uncertain, the admin can check the channel and reconcile the result before retrying.
- Admins can edit and close listings on the site. Update an existing Telegram post in the channel when its published details change.

### 🧭 A searchable Features directory

- Moved the eight Home feature cards into **Features**. Open it from **Browse all features** beneath the Home introduction or from the mobile bottom navigation.
- Search by name or description, filter by **Academic**, **Career**, **Tools** or **Planning**, and find tools in grouped cards. Frequently used shortcuts are ranked from usage saved in the current browser.
- Unified the entry headings and control panels across the feature pages, using the same styling as Student Compass and Career Board. The entry arrow takes users directly to [Features](https://unecstudentshub.com/#/functions). Article, subject and material views retain their own navigation.

### 📱 A simpler mobile sidebar and GPA calculator

- Removed the 11 navigation links from the mobile sidebar. Signed-in users see their XP and rank card near the top. A **Support** card at the bottom has a dedicated button to open the Support page.
- Simplified the GPA subject count by removing the two extra stepper buttons. The count updates when users add a subject with **Add new subject** or remove a subject from its row.

### 📄 About, Privacy Policy and Terms of Use

- Expanded all three sections in Azerbaijani and English. The updated content covers the project and its tools, account and study data, public discussions, AI, payments, copyright and community rules.
- Added contents navigation to the Privacy Policy and Terms of Use. Each section ends with a **Contact us** card for complaints, suggestions and questions. Its button opens a Gmail draft addressed to `unecstudentshub@gmail.com`.

### 📚 Eight new study PDFs

- Added **five written midterm PDFs** for International Economics, Labour Economics, Microeconomics and Pricing Policy.
- Added **three semester test PDFs** for International Management, Management and Civil Defence. International Management was added to the catalogue under subject code **00175**.
- Recorded the addition time as **19 November 2026 at 20:05 Baku time** and regenerated the public pages, sitemap, catalogue history, mobile catalogue and practice-source lists. The catalogue now contains **174 entries covering 167 distinct files**.

## 🧪 Quality checks

- **167 JavaScript tests and 3 Python tests passed.** The generated-site, material-date and JavaScript syntax checks also passed.
- Browser checks covered feature navigation, search and filtering, offline access to the Features directory, mobile sidebar layout, GPA subject controls, career drafts and bilingual policy dialogs. Test fixtures were used for admin data, Telegram delivery and Gmail navigation.

## 🚀 Deployment

The frontend uses GitHub Pages and the backend uses Vercel. Career listings use the existing Firebase service account and admin access key. Automatic Telegram posting requires `CAREER_TELEGRAM_BOT_TOKEN` in Vercel and a bot with permission to post in the career channel. See the [service setup guide](https://github.com/EricIsMyHero/ericismyhero.github.io/blob/v1.1.26/ai-vercel/SERVICE-SETUP.md#karyera-lövhəsi).

New PDFs use the existing Cloudflare R2 material paths. The generated practice-source lists are included in the Vercel backend update.
