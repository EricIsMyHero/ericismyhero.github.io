# UNEC Students Hub v1.1.22

Student Compass, a rebuilt administration panel with a content workspace, and simpler material information pages.

## ✨ What's new

### 🧭 Student Compass

- Added **Student Compass (Tələbə Kompası)** with **20 articles in Azerbaijani and English** for students and university applicants. Open it from Home, the sidebar, the mobile menu or More.
- Topics include admission, registration, student rights, documents, study funding, work, housing, exchange programmes and military-service deferment.
- Detailed guides cover **stipend amounts**, **four separate UNEC campuses**, the **25% resit-fee ceiling**, **summer school**, **repeating a course with another group**, and **academic leave**. Fee guides explain the calculation with examples; actual tuition charges depend on the programme fee and credits.
- Search article text, filter by audience or topic, save articles locally and share public links. Articles include reading times, review dates, practical next steps and official sources. Cached articles remain readable offline after an online visit; external sources need a connection.

### 🛠️ A rebuilt administration panel

- Redesigned navigation, responsive layouts and light/dark appearance. User lists support search, sorting, pagination and CSV export; request and premium-code lists have status filters.
- Added a **content workspace** for posts, stories, release notes, material appeals, notification drafts and technical checks. Switch between table and board views, track status, priority and owner, and record text, links, review notes and target/actual results.
- Create, edit, duplicate, delete and copy tasks, or transfer them using JSON export/import. **Workspace tasks stay in the current browser** and do not synchronise between devices or administrators. Drafts do not automatically publish to social networks or send notifications.
- The GitHub view reads recent public commits. Request threads, attachments, per-message notification results, premium-code creation and the separate push sender remain available.

### 📄 Cleaner material information pages

- Removed the generated description beneath **Summary**, retaining the course, semester, format, subject code, filename and available file-size cards.
- Removed the duplicate **Subject page and discussion** and **Report an issue** links below Download. Both actions remain in the **three-dot menu**.
- File opening, downloading, favorites, ratings and related-material groups remain available.

## 🛠️ Improvements

- Curriculum subject rows always show **credits and absence limits**. Total hours and weekly workload appear in each semester's summary; the printable plan follows the same layout.
- Removed the Home feature-search field and improved Compass titles, filters, source links and financial tables on small screens.
- Corrected admin statistics to match the actual profile, chat and rating fields. Account reads follow database pagination, including progress records; chats remain discoverable when their parent document is missing.
- Capped admin datasets are identified, PDF opening statistics use the latest 500 timestamped events, and read errors are shown instead of misleading zero totals.
- Admin credentials remain in page memory. Logout cancels pending requests and clears private views; private API responses are not cached. Premium codes use cryptographic randomness, and incomplete batches return any codes already created.
- Refreshed catalog records and public material pages for **142 entries covering 132 distinct files**, preserving recent material additions and category corrections. Updated asset versions, the offline cache and documentation.

## 🧪 Quality checks

- **30 automated tests passed**, covering existing study/account features, Compass validation and search, admin authentication, data mappings, pagination and partial code-generation failures.
- Browser checks covered **320–1440px**, Azerbaijani/English content, material-menu actions, Compass offline reading, admin table/board views, JSON import/export, clipboard actions and logout cleanup. Administrative mutation flows were tested with fixtures.
- Generated pages, material-date history and JavaScript syntax checks passed. The live frontend and the admin API's unauthenticated rejection were verified; GitHub Pages, Vercel and repository checks succeeded.

## 🚀 Deployment

Frontend and backend changes are deployed through the existing GitHub Pages and Vercel setup. Use the existing admin access code. No new runtime dependencies, environment variables or database migrations are required for this release; existing service configuration still applies.

Workspace storage and administration behaviour are documented in the [README](https://github.com/EricIsMyHero/ericismyhero.github.io/blob/v1.1.22/README.md#administration).
