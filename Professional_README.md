## Overview

UNEC Students Hub is an independent platform that brings together
academic resources, productivity tools, AI powered features, and student
services in one place.

## Getting Started

``` bash
git clone https://github.com/EricIsMyHero/ericismyhero.github.io.git
cd ericismyhero.github.io
python3 -m http.server 8080
```

Open `http://localhost:8080`
